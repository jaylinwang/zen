首个公开版本：原生、离线、本地文件优先的专注计时工具。

- macOS 菜单栏与主窗口，自定专注 / 休息时长。
- 木鱼、松风、细雨陪伴音，独立磬声结束提醒。
- 专注后补记、草稿恢复和可读 Markdown 记录；主动放弃不留痕。
- 全局快捷键、系统通知、登录启动及文件冲突保护。

### 下载与安装

下载下方 `Zen-0.1.0-macOS-universal.dmg`，适用于 macOS 13+ 的 Apple Silicon 和 Intel Mac。打开 DMG，将「禅」拖到 Applications；首次运行后在设置中选择记录文件夹。

安装包由 GitHub Actions 构建，使用 ad-hoc 临时签名，**尚无 Developer ID 签名和 Apple 公证**。首次运行可能被 Gatekeeper 拦截。确认下载来源后，请参阅 [Apple 官方打开说明](https://support.apple.com/zh-cn/102445)，按系统提示在「隐私与安全性」中允许此应用。

可下载 `SHA256SUMS.txt` 并在同目录执行 `shasum -a 256 -c SHA256SUMS.txt` 校验文件完整性。

iPhone 暂提供源码构建，没有 IPA 或 App Store 下载；真机锁屏音频、通知和外部文件提供程序仍待验收。应用记录为明文文件，跨设备同步由使用者自行安排。

代码采用 MIT 许可证，内置录音采用 CC0，完整署名随安装包提供。
