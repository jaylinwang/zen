## 需要保留的边界

- 不监听应用切换、锁屏或用户活动判断专注。前后台生命周期只用于重新显示计时结果和读取文件。
- 不在到时回调中创建窗口或激活 App，通知由系统处理；点击通知后才打开待补记。
- 运行状态和草稿属于本机，正式记录可外部同步。冲突不是自动合并，外部同步传输不属于 App 功能。
- Markdown 文件和草稿都有稳定会话 ID。成功写入正式文件后才清理草稿；崩溃后重试以已写入的内容去重。
- 主动放弃不生成文件或补记，并清除当前会话恢复状态。旧版放弃记录保留但不计入累计，可明确删除。
- 一条记录一个文件是从 PRD 建议采用的格式。补记只更新该记录，不创建待办。
